# 🎃 Halloween Git Rescue

## Presentació

Aquest projecte simula una investigació de **Forensic Software** durant la nit de Halloween.

L'objectiu de l'activitat és aprendre a utilitzar Git per crear commits, treballar amb branques, provocar i resoldre conflictes, tornar a una versió anterior del projecte i publicar el resultat final a GitHub.

Durant la pràctica s'han creat dues línies temporals diferents: una dimensió fosca i una línia de protecció. Finalment, les dues versions s'han fusionat i el codi infectat ha estat eliminat.

## Entorn utilitzat

- **Sistema operatiu:** Windows
- **Terminal:** PowerShell
- **Editor:** Visual Studio Code
- **Llenguatge:** Java
- **Control de versions:** Git
- **Repositori remot:** GitHub

### [Bloc 1: Invocació del Repositori i Línia Base](BLOC1.md)

Creació del repositori, configuració de Git i primers commits del projecte.

### [Bloc 2: Les Branques del Més Enllà i Resolució del Conflicte](BLOC2.md)

Creació de les branques `feature-nightmare` i `feature-sanctuary`, fusió de les dues línies temporals i resolució manual del conflicte.

### [Bloc 3: Viatge Temporal, Exorcisme del Codi i Publicació Remota](BLOC3.md)

## Resultat final

El repositori ha estat recuperat correctament, el conflicte entre les branques s'ha resolt i el commit infectat s'ha eliminat de la branca principal.
